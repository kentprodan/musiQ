# musiQ — Android clients (placeholder)

Not implemented yet. Planned: Jetpack Compose (Material 3 Expressive
design language) for phone, tablet, Android TV, and Wear OS.

Will consume `core/musiq-core` through Kotlin bindings generated by
`uniffi-bindgen` from the shared contract in `ffi/musiq-uniffi` — the same
FFI boundary the Windows and Apple clients use. The native `.so` will be
built separately (e.g. via `cargo ndk`) and is not part of this repo.

See [`docs/architecture.md`](../../docs/architecture.md) for the overall
plan. This folder intentionally contains no code yet.
