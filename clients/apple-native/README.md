# musiQ — Apple clients (placeholder)

Not implemented yet. Planned: SwiftUI (Liquid Glass design language) for
macOS, iOS, iPadOS, tvOS, watchOS, visionOS, and CarPlay, sharing one
Swift package across targets.

Will consume `core/musiq-core` through Swift bindings generated by
`uniffi-bindgen` from the shared contract in `ffi/musiq-uniffi` — the same
FFI boundary the Windows and (later) Android clients use.

See [`docs/architecture.md`](../../docs/architecture.md) for the overall
plan. This folder intentionally contains no code yet.
